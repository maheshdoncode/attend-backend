# API Documentation Rule

- Always maintain the living `API_DOCS.md` file in the project root.
- Whenever an API route, controller, endpoint, middleware, or request/response signature is added, updated, or removed, you MUST proactively update `API_DOCS.md` using the `api-documenter` skill template.
- Keep request schemas, authentication requirements, query params, URL parameters, error codes, and response JSON accurate and up-to-date at all times.
